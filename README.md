# One Star, Written in Sap — make.fun entry

A one-line 1-star review by a houseplant about its human owner, under 280 characters:

> ★☆☆☆☆ My human waters me on a schedule he found online, for a plant he has never actually met. I am a fern, not a cactus, Greg.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–279 character rule.
